Right Click and Copy Support

How do I use the extension?

Open a regular website, click the extension’s toolbar icon, and turn Enable on this site on. Changes apply immediately.

What is Strong Mode?

Strong Mode is an optional per-site setting for pages that repeatedly clear a fresh text selection. It also unblocks drag actions. Use it only when standard mode is not enough.

Why does the popup say “Unavailable”?

Chrome prevents extensions from running on protected pages such as chrome:// URLs, the Chrome Web Store, and some built-in browser views.

How do I clear saved preferences?

Change the relevant site setting, clear the extension’s stored data in Chrome, or uninstall the extension.

Report a problem

Open an issue in the GitHub repository that hosts this page. Include your Chrome version, the affected website, and reproducible steps. Do not include passwords, private page content, or other sensitive information.
